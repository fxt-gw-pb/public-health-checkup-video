# Remotion 动画清单（由 Claude 制作）

> 这些是 AI 视频做不好、或者需要精确控制的部分：**所有可读文字、数据、转场、分屏、片头片尾和最终合成**。
> 每一项都有编号 R01–R16，与 `02_seedance/00_分段总表.md` 的成片顺序对应。

## 0. 全局规范

| 项目 | 规格 |
|---|---|
| 合成尺寸 | 1920×1080，24fps |
| Seedance 素材 | 720P 放大到 1080P；每段按"可用时长"裁剪 |
| 标题 / 花字字体 | ZCOOL KuaiLe（站酷快乐体），`@remotion/google-fonts` 加载 |
| 正文 / 字幕字体 | Noto Sans SC（思源黑体），Bold / Regular |
| 颜色 | 全部取自 `00_全局设定/01_风格圣经.md` 第 3 节 |
| 字幕 | 底部居中，距底边 80px；Noto Sans SC Bold 48px，白字 + 6px 墨褐描边 `#2B2420`；每行不超过 16 个字；说话人不标名字 |
| 安全区 | 四边各留 5%，所有文字不出安全区 |
| 招牌音效 | 每次算珠转场、章节卡出现都配同一个"噼啪"算盘声 |

**动画手感统一**：所有弹出动画用 `spring`（damping 12–14，有一点回弹），淡入淡出 6–8 帧。像算盘珠落位的感觉：快、脆、有一点弹。

## 1. 转场与章节（全片复用的组件）

### R04 算珠转场 `<BeadWipe>`（用 5 次）
- **时长**：24 帧（1 秒），前后两段各重叠 12 帧
- **动画**：13 颗算珠（A04 素材）排成一列竖着的"档"，从画面左侧外飞速滑到右侧外；珠子经过的地方露出下一段画面。最后一颗珠子落位时配"噼啪"音效
- **用在**：SEG02→SEG03、SEG06→SEG07、SEG07→SEG08、SEG10→SEG13、SEG17→SEG18

### R05 三本账簿 / 章节卡 `<LedgerChapter>`
- **R05-1（3s，SEG04 之后）**：SEG04 结尾的算珠特写放大到填满画面 → 白闪 → A03 纸张底上，三本账簿（A02 金/蓝/绿）从画面下方依次弹入并排站好，贴签上写"金钱账""时间账""健康账"（站酷快乐体，墨褐色）→ 金色那本放大、翻开 → 翻开的书页变成 SEG05 的账簿空间
- **R05-2（2.5s，SEG09/R09 之后）**：纸张底，蓝色账簿从右侧滑入，贴签"第二笔·时间账"，翻开
- **R05-3（2.5s，SEG14 之后）**：同上，绿色账簿，"第三笔·健康账"
- 三次的版式完全一致，只换颜色和文字，形成节奏感

## 2. 片头片尾

### R01 人物介绍花字（3s，叠在 SEG01 上）
- SEG01 第 10–11 秒的得意表情**定格**，画面轻微推近（scale 1.0→1.06），背景压暗 20%
- 左侧依次弹出两行花字（站酷快乐体，白字 + 琥珀金描边）：
  - **周建国，56 岁，会计三十年**
  - **人称"周铁算"**
- 第三行稍晚出现，字号更大：**这辈子，没算错过一笔账。**
- 配一声"噼啪"

### R02 片名卡（3s）
- A03 纸张底。一排算珠从左往右"啪啪啪"依次落位，每落一颗出现一个字：**周 · 铁 · 算 · 的 · 三 · 笔 · 账**
- 下方小字淡入：**主动体检，科学体检**

### R16 片尾行动卡（8s）
- A03 纸张底，标题：**主动体检 · 科学体检**
- 三条依次弹入，每条左边是对应颜色的算珠：
  1. 🟡（金）**45 岁起，给自己建一份健康"底账"**
  2. 🔵（蓝）**按自己的风险选项目，问问家庭医生**
  3. 🟢（绿）**报告上有箭头，3 个月内去复查**
- 底部小字：3 大组第 4 小组 ｜ 数据来源：中国慢性病及危险因素监测等（见作业报告参考文献）
- 最后响三声"咔哒"，和 SEG18 呼应

## 3. 插入画面（替代 AI 生成文字的部分）

### R03 手机通知（约 1.5s，插在 SEG02 第 5–6 秒）
- A05 手机外框，屏幕里是一个简洁的锁屏通知卡片：
  - 标题：**【单位工会】年度体检预约提醒**
  - 正文：**本年度职工体检已开始预约，请于本月底前完成。**
  - 下方两个按钮："立即预约"（灰）、**"稍后提醒"**（被拇指图标点中、高亮）
- 动画：手机从下方滑入 → 拇指点"稍后提醒" → 通知卡"嗖"地被划走

### R06 金钱账栏目标签 + "亏"字（叠在 SEG05 镜头1）
- 依赖 SEG05 镜头1 **固定机位**
- 账簿左栏顶部写"**体检**"，右栏顶部写"**不查**"（站酷快乐体，墨褐色，像手写在账簿上，带一点纸面透视）
- 老周说"亏"时，他头顶上方"盖"下一个红色印章字"**亏**"（警示红，带印章边框和轻微抖动）
- 算珠飞到"亏"字位置的那一帧，"亏"字被撞飞、旋转着飞出画面
- 需要 Claude 对照生成的视频手动对齐坐标和帧号

### R07 体检套餐购物页面（约 2s，插在 SEG07 第 2–4 秒）
- A05 手机外框，屏幕里是购物 App 风格的商品页（不模仿任何真实 App 的品牌）：
  - 商品名：**至尊豪华全身 VIP 体检套餐**
  - 价格：**¥8888**（红色大字）
  - "加购"按钮被疯狂点击，购物车角标数字 1→2→5→12→27 飞速上涨，每点一下弹出"+1"
- 节奏越来越快，最后一下按钮"爆"开

### R08 清单特写文字（叠在 SEG07 镜头3）
- 依赖 SEG07 镜头3 **固定机位俯拍**
- 纸条横线上依次"打印"出项目名（Noto Sans SC，深灰，像小票打印字）：
  - 血常规 / 尿常规 / 全身 PET-CT / 肿瘤标志物全套 / 骨密度 / 基因检测 / 心脏彩超 / **妇科彩超** / 微量元素 / ……
- 算盘爷手指按住的那一行（"妇科彩超"）高亮为黄色底，其他行稍微变暗
- 备选文字（如组里决定换掉）：**儿童生长发育评估**

### R09 科学体检字卡（3s，SEG09 之后）
- A03 纸张底，琥珀金主题
- 版式像一道算式，一项一项弹出：
  > **科学体检 = 基础项目 + 按个人风险加项**
- 下方小字：血压 · 血糖 · 血脂　｜　吸烟、家族史、年龄……
- 最后"="号处配一声"噼啪"

### R10 时间账分屏（12s，SEG10 镜头2 之后）
- 画面一分为二，中间一条黄铜色竖线（像算盘的横梁竖过来）
- **左半**：SEG11 裁中间竖条；顶部标签"**去查**"（天蓝底白字）；右上角数字时钟 **8:00 → 11:30**，跟着画面一起快进；结尾出现大字"**一个上午**"
- **右半**：SEG12 裁中间竖条，整体压一层淡淡的冷灰滤镜；顶部标签"**不查**"（灰底白字）；日历年份 **2026 → 2027 → 2028……** 往上翻
- 算盘爷画外音（后期配）："体检，是一个上午；拖出来的病，是一年一年地还。"
- 结尾左边亮起、右边淡出，切回 SEG10 镜头3

### R11 角标"体检：一个上午"（叠在 SEG14 镜头2）
- 右上角，天蓝色圆角标签，白字，带一个小钟表图标，弹入后停留 3 秒

### R12 报告特写（约 1.5s，插在 SEG15 第 2–3 秒）
- A06 体检报告模板，表格里填入（Noto Sans SC）：
  | 项目 | 结果 | 参考范围 | 提示 |
  |---|---|---|---|
  | 血压 | 正常 | | |
  | 空腹血糖 | 正常 | | |
  | 总胆固醇 | 偏高 | | **↑** |
  | 甘油三酯 | 偏高 | | **↑** |
- 镜头快速推向红色"↑"，箭头一跳一跳地放大 → 接 SEG15 镜头2 的红色恐慌
- 只写"正常 / 偏高"，**不写具体数值**，避免数值出错

### R13 数据卡（4s，SEG15 之后）
- A03 纸张底，青绿主题
- 大字：**血脂异常的人里，不到两成知道自己有这个问题**
- 一个 10 格小人图标，只有 2 格亮起（18.2%）
- 小字来源：Xia Q, et al. 2023（血脂异常知晓率 18.2%）
- 最后一行弹出：**早发现 · 能管住**

### R14 假片尾"全剧终"被撕（4s，SEG17 镜头1 与镜头2 之间）
- SEG17 镜头1 结尾的伸懒腰姿势**定格**，温暖音乐渐强，画面四周暗角加重
- 正中央大字淡入：**全剧终**（站酷快乐体，白字，像老电影片尾）
- 停半秒，音乐突然"刺啦"一声唱片划停
- A01-1 算盘爷"扒边"从画面下边缘爬上来 → 换成 A01-2"拽"的姿势，抓住"**终**"字往下拽 → "终"字被扯掉、翻转着掉出画面，只剩"全剧"
- 算盘爷 A01-3"叉腰"瞪向画面左侧（五斗柜方向）→ 切 SEG17 镜头2

### R15 手机提醒（约 2s，叠在 SEG17 结尾）
- A05 手机外框从右下角滑入，屏幕显示：
  - ✅ **提醒设置成功**
  - **3 个月后 · 血脂复查**
- 配手机"叮"音效（和视频里的"叮"对齐）

## 4. 字幕与合成

- **R17 全片字幕**：所有对白按 `04_音频/配音与音效.md` 的台词表制作，严格按配音时间轴对齐
- **最终合成**：所有 SEG 片段 + R 动画 + 配音 + BGM + 音效，统一调色（整体轻微加暖、对比度统一），输出 MP4（H.264，1080P）

## 5. 制作顺序（Claude）

1. 素材到位前：先搭 Remotion 项目，做好 R01、R02、R04、R05、R09、R13、R16 这些**不依赖视频**的部分，用占位图预览
2. SEG 视频陆续到位后：做 R03、R06、R07、R08、R10、R11、R12、R14、R15 这些**需要对齐视频**的部分
3. 配音到位后：做字幕，最终合成
