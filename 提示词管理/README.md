## 制作流程（严格按顺序）

```
① 角色设定图 C01 → C02 → C01b/C02b → C03/C04/C05 → C06    【组里一起选定，最关键】
② 场景图 L01–L09（L03b 必须用 L03a 改）
③ Remotion 素材 A01–A06（可以和 ④ 同时做）
④ 分段首帧 K01–K18
⑤ Seedance SEG01 → SEG18（按顺序：有"尾帧接首帧"的段落必须等上一段选定）
⑥ Claude：抽尾帧、截参考音频、检查连贯性 → 做 Remotion 动画 → 字幕 → 合成
```

每完成一项，在 `05_进度表.md` 里改状态、登记文件名。

## 保持一致性的 7 条规则

1. **标准描述原样复制**：角色、场景、风格段落都从 `00_全局设定/` 复制，不要自己改写。
2. **参考图永远带上**：每次生成都上传选定的角色设定图和场景图，顺序按 `00_分段总表.md`。
3. **首帧先行**：Seedance 每段都以首帧开始；同一场景连续的两段，用上一段的尾帧作为下一段的首帧。
4. **AI 不写字**：画面里所有要看清的文字都由 Remotion 加，AI 生成的画面里出现乱码就重抽。
5. **固定机位镜头别动**：要叠文字的镜头（SEG05 镜头1、SEG07 镜头3、SEG17 镜头1）机位一动就重抽。
6. **声音用参考音频**：第一次出满意的声音后，后面的段落都上传它。
7. **Seedance 不生成音乐**：音乐由后期统一加，保证全片连贯。

## 即梦 CLI 自动生成（2026-10-20 起主力方式）

- 账号：即梦会员（artisan），模型 **`seedance2.0_vip`**，15 秒 720P **每条 210 积分，提交时扣**，排队约 4 分钟；
  普通版 `seedance2.0` 每条 120 分但要排约 8 小时，不用。上传失败、并发已满、取消排队都不扣分
- SEG11、SEG12（时间账分屏）改由 Remotion 用静帧做，不走 Seedance
- **同一时间只能跑一个任务**，所以用排队程序串行生成：
  `python3 提示词管理/tools/queue_run.py SEG04 SEG05 …`（日志：`素材/05_seedance视频/queue.log`）
- 素材顺序看 `02_seedance/提交清单.json`；单段提交 / 查询 / 打网页包用 `tools/seedance.py`
- 每次提交都记在 `素材/05_seedance视频/生成记录.md`（人看）和 `submissions.json`（程序用）
- 排队程序会自动：抽尾帧（SEG01/05/08/13）、截参考音频（SEG04 → 算盘爷，SEG08 → 李医生）

## Seedance 平台操作要点（网页平台，备用）

- 模式选**"全能参考"**，比例**横屏 16:9**，清晰度 **720P**，时长固定 15 秒
- 参考图最多 9 张（每张 ≤ 5MB），参考音频最多 3 段（每段 2–15 秒、合计 ≤ 15 秒，mp3/wav）
- 提示词里用 `@图片1`、`@音频1` 引用，**上传顺序决定编号**
- 如果"全能参考"一致性不好，可以改用**"首帧"**模式，只上传首帧，把提示词里的角色描述换成 `00_全局设定/02_角色卡.md` 里的完整标准描述
- 平台显示"余额偏低"，18 段加上重抽，建议预留约 30 次生成的额度
