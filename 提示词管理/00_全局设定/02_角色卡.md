## C01 老周（周建国）

**身份**：56 岁，厂里会计三十年，在职。人称"周铁算"。精明、抠门、嘴硬，但心不坏。

**标准描述（复制用）：**
```
老周：56岁中国男性，身高中等，微胖，有明显圆滚滚的啤酒肚。圆脸，短平头，头发黑中带灰、两鬓斑白，浓黑的眉毛，单眼皮小眼睛，眼神精明，嘴角常挂着一丝算计得逞的笑，左边眉尾有一颗小黑痣。胸前用黑色细绳挂着一副金属细框老花镜。穿藏青色立领拉链夹克，里面是浅灰色圆领毛衣，深灰色休闲裤，黑色布鞋，腰带上挂着一串钥匙。
```

**服装变体：**
| 变体 | 描述 | 用在 |
|---|---|---|
| 外出（默认） | 如上 | 菜市场、公园、诊室、尾声 |
| 居家 | 脱掉夹克，只穿浅灰色圆领毛衣和深灰色休闲裤，脚穿深蓝色棉拖鞋，老花镜仍挂胸前 | 客厅所有场景 |
| 伪装 | 外出服装 + 黑色大墨镜、白色一次性口罩、黑色鸭舌帽，夹克领子竖起 | 体检中心门口 |
| 尾声 | 外出服装，钥匙串上多了一个巴掌大的小算盘挂件（算盘爷缩小版） | 尾声菜市场 |

**表演要点**：砍价时眼神坚定、一动不动；得意时嘴角单边上扬；被戳穿时眼神飘忽、嘴硬。

## C02 算盘爷

**身份**：老周家墙上挂了三十年的老算盘，老周当会计时的"战友"。只有老周能看见它说话（医生看不见）。慢条斯理、毒舌、护主。

**标准描述（复制用）：**
```
算盘爷：一把会动会说话的老式木算盘（拟人化卡通角色），宽约50厘米、高约25厘米。深红棕色实木边框，表面有被岁月磨亮的光泽，四个角包着黄铜包角。中间一根横梁把珠子分成上下两层：上层每档2颗、下层每档5颗深棕色圆润木珠，一共13档。横梁正中央有一双大大的卡通眼睛（白眼球、黑瞳孔、很有神），眼睛上方架着一副小小的黄铜圆框老花镜。眼睛下方、下层珠子中间有一张粉红色的卡通嘴巴，说话时嘴巴一张一合。边框左右两侧各伸出一条细细的黄铜色小胳膊，末端是白色卡通手套小手；底边伸出两只短短的木头小脚。
```

**状态变体：**
| 状态 | 描述 | 用在 |
|---|---|---|
| 沉睡 | 挂在墙上钉子上，**没有眼睛、没有手脚**，就是一把普通的旧算盘，落了一层薄灰 | 夜·客厅开场 |
| 醒来（默认） | 如标准描述 | 大部分场景 |
| 包中 | 从老周的米色帆布手提包里探出上半截，只露眼睛和一只小手 | 诊室 |
| 挂件 | 缩小到巴掌大，挂在老周钥匙串上，造型不变，仍有眼睛 | 尾声 |

**表演要点**：拨珠子是它的"招式"——说重点前总要"啪"地拨一颗珠子；生气时珠子乱响；得意时推一推小眼镜。

## C03 老刘

**身份**：58 岁，老周的公园棋友，爱刷短视频，"体检无用论"代言人。爱抬杠，最后却偷偷去体检。

**标准描述（复制用）：**
```
老刘：58岁中国男性，又高又瘦，比老周高半个头，长脸、尖下巴，颧骨突出，稀疏的头发往后梳，留着两撇灰白的八字小胡子，眼睛细长。穿一件卡其色多口袋钓鱼马甲，里面是白色短袖衬衫，浅灰色长裤，白色运动鞋。手里总拿着一部手机，马甲口袋里插着一个银色保温杯。
```

**变体**：伪装——黑色大墨镜、白色一次性口罩（体检中心门口）。

## C05 配角组

**标准描述（复制用）：**
```
菜摊大姐：50岁左右中国女性，矮胖，圆脸红润，扎低马尾，系红色围裙，戴深蓝色袖套，嗓门大，表情生动。
王阿姨：60岁左右中国女性，烫着短卷发，笑容热情，穿红色带白条纹的运动外套（广场舞队服），黑色运动裤。
广场舞队员：四五位60岁左右的阿姨和大爷，全都穿和王阿姨同款的红色白条纹运动外套。
小孙子：老周的孙子。小时候版本：4岁左右的男孩，圆脸，戴黄色幼儿园小帽，背着小水壶。长大版本：8岁左右，同一张脸长开了，背着蓝色双肩书包。
```

## 角色关系与比例（C06 用）

- 身高从高到低：老刘 > 老周 ≈ 李医生 > 王阿姨 ≈ 菜摊大姐 > 小孙子（8 岁）> 小孙子（4 岁）
- 算盘爷宽度约等于老周的肩宽；挂件版约等于老周的手掌。
