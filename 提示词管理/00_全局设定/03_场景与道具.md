### L01 菜市场菜摊
```
清晨的室内农贸市场，一排排绿色铁皮菜摊，头顶挂着暖黄色灯泡，空气里飘着薄薄的蒸汽。画面中心是一个蔬菜摊：木板台面上整齐码着大葱、白菜、西红柿、青椒，台面边放着一台旧电子秤和一个装零钱的铁盒，摊位后面挂着几个红色塑料袋。远处有模糊的人影在买菜。
```

### L02 公园长椅
```
上午的城市公园，一棵枝叶茂密的老槐树下放着一张木条长椅，长椅旁有一张石桌，桌面刻着象棋棋盘，上面摆着几枚木头棋子。背景是一片小湖和柳树，远处有人在打太极、遛鸟。阳光透过树叶洒下斑驳光影。
```

### L03 老周家客厅（日、夜共用同一布局，必须一致）
```
中国北方老小区里的客厅，90年代装修风格，米黄色墙面，浅色木地板。画面左侧靠墙是一个深棕色木质五斗柜，最上层是一个宽抽屉；五斗柜上方的墙面上钉着一颗钉子，挂着一把老式木算盘。画面中间是一张米色布艺三人沙发，沙发上有两个格子靠垫，沙发前是一张木茶几，茶几上放着一个白色搪瓷茶缸和一盘瓜子。画面右侧是电视柜和一台液晶电视，墙上挂着一个圆形挂钟。右后方墙角靠着一根收起来的鱼竿。右侧有一扇窗，挂着浅绿色窗帘。
```
- **L03a 夜**：在上面描述后加：`夜晚，窗外是深蓝色夜空，室内亮着沙发旁的落地灯和五斗柜上的台灯，暖黄色光线，角落偏暗。`
- **L03b 日**：在上面描述后加：`白天，柔和的日光从右侧窗户照进来，室内明亮温暖。`

### L04 账簿空间（幻想）
```
一个奇幻的空间：地面是一本无边无际、巨大摊开的老式账簿，纸面是暖米黄色，印着淡红色的竖格和横线，纸张有细腻的纹理和轻微的折痕。账簿正中间有一条粗的红色竖线，把纸面分成左右两栏。空间没有明确的天空和墙壁，远处是柔和的暖色光晕，空中漂浮着几颗巨大的深棕色算珠和几页纸。光线柔和，像是从纸面里透出来的。
```

### L05 社区卫生服务中心诊室
```
社区卫生服务中心的诊室，干净明亮，墙面下半部分是浅绿色、上半部分是白色。一张浅木色诊桌，桌上有一台电脑显示器、一台电子血压计、一个笔筒和一沓病历。医生坐的是黑色办公椅，对面是给病人坐的圆凳。背后墙上挂着人体示意图（无可读文字）和一个洗手池。窗外是绿树。
```

### L06 体检中心门口
```
清晨，一栋现代风格的体检中心门口，大块玻璃自动门，门前有三级浅灰色台阶和不锈钢排队栏杆，门旁种着两盆绿植。墙角有一个拐角，可以让人从侧面走出来。晨光是暖金色，地面微湿。门楣上的招牌没有可读文字。
```

### L07 体检中心大厅
```
体检中心大厅，明亮整洁，白色和浅蓝色为主，墙上挂着一个很大的圆形挂钟（只有刻度，没有数字），大厅里有几个检查室的门、抽血窗口和一排浅蓝色候诊椅，穿浅蓝色衣服的护士在走动。
```

### L08 医院走廊
```
医院住院部的长走廊，墙面淡青灰色，一侧是一排蓝色金属候诊椅，坐满了排队的人，走廊尽头是窗户。光线偏冷，但整体仍是温和的卡通风格，不阴森。
```

### L09 路边早点摊
```
上午阳光下的路边早点摊，一口大油锅正在炸金黄的油条，旁边摞着竹蒸笼冒着热气，一张折叠桌配几张蓝色塑料凳，桌上摆着白瓷碗装的豆浆、一盘油条和几个包子。背景是老街和树荫。
```
