# 风格圣经（所有提示词的源头）

> 这里是全片画风、色彩、镜头和禁忌的**唯一定义**。其他文件里的风格段落都从这里复制。
> 如果要改画风，先改这里，再让 Claude 把所有提示词统一替换，不要只改单个文件。

## 1. 画风（已定：2D 卡通动画，粗描边 + 平涂）

2026-10-20 改定。原因：3D 版本试了两次都偏写实，"AI 味"重；2D 平涂更像真正的动画片，也和 Remotion 做的字卡、抠图动画更搭。

**为什么选"粗描边 + 平涂 + 一层阴影"这种 2D**：AI 视频做 2D 时最常见的问题是线条抖动、颜色闪烁、角色走样。线条越粗越简单、颜色块越少，这些问题越不明显。所以这里刻意选了最"好画"的那一类 2D，而不是细线条、多层光影的精致画风。

### 1.1 风格段落 · 给 image 2.5 用（完整版）

```
【画风】2D卡通动画风格，像电视上播的家庭喜剧动画片：统一粗细的深褐色描边，线条干净、圆润、偏粗，不要细碎线条；平涂上色，每块颜色最多加一层简单的硬边阴影，不要渐变、不要高光、不要立体光影；造型简单夸张，大头小身体，头身比约1:3，五官用简单的形状概括，只用一两根线表示皱纹；头发是一整块简单的形状；手是圆润的简化卡通手。整体配色温暖：米黄、木棕、暖橙为主，饱和度适中。故事发生在2020年代中国北方城市的老小区和社区里，生活气息浓。
【禁止】不要3D、不要立体渲染、不要写实或半写实，不要渐变和光泽高光，不要细碎的线条和纹理，不要日系二次元美型风，不要画面中出现任何可读文字、字幕、水印、logo；手指数量正确，五官不变形。
```

### 1.2 风格段落 · 给 Seedance 用（精简版，每段提示词末尾都要带）

```
【风格】2D卡通动画风格，与参考图完全一致：统一粗细的深褐色描边，平涂上色加一层简单阴影，简单夸张的造型，大头小身体，温暖明亮的光线，暖色调，中国北方老城区生活气息。画面流畅，动作有卡通弹性（挤压与拉伸），表情夸张清晰。
【约束】保持2D平面卡通画风，不要变成3D或立体光影，线条在运动中保持稳定、不抖动、不闪烁；所有角色的脸型、发型、服装、体型必须与参考图完全一致，全程不变脸；画面中不出现任何可读文字、字幕、水印；不要背景音乐（音乐后期统一加），保留对白和音效。
```

## 5. 镜头语言

- **固定机位优先**：凡是后期要叠加文字的镜头（账簿两栏、清单特写、报告特写），提示词里一律写"固定机位，镜头不动"，方便 Remotion 对齐文字。
- **一段 15 秒最多 4 个镜头**；每个镜头只做一件事。
- **段尾留余量**：每段最后 1–2 秒让人物保持姿势或停顿，留给剪辑和转场。
- **对白镜头用中景或近景**，保证口型看得清。
- **笑点镜头给反应**：每个笑点后面都要有一个角色的反应镜头（愣住、翻白眼、咽口水）。

### 2D 专项规则（防止线条抖动和变脸）

- **机位只用平移、推拉和固定**，不要环绕、旋转机位（2D 画面一转就会穿帮）。
- **动作要简单、幅度明确**：一个镜头一个动作；不要同时出现很多人一起做复杂动作。
- **少用细节多的大全景**：人物在画面里太小，五官容易糊、容易变脸；对白镜头保持中景或近景。
- **每段都上传角色设定图和首帧**，2D 比 3D 更依赖参考图。
- 生成后重点看：线条有没有抖、颜色有没有闪、有没有突然出现 3D 光影。

## 6. 文字规则（重要）

**AI 视频里不生成任何可读文字。** 手机屏幕、清单、报告单、缴费单、日历、"全剧终"等所有需要看清的中文，一律由 Remotion 后期叠加。
- 在 Seedance 提示词里写："屏幕背对镜头" "纸面上只有模糊横线，无可读文字"。
- image 2.5 出的设定图同样不要文字标注。

## 7. 招牌元素（全片反复出现，制造统一感）

1. **算盘声"噼啪"**：每次转场、每次算盘爷"出招"都配同一个算盘音效。
2. **算珠转场**：一排算珠从左往右滑过画面，完成换场（Remotion 制作）。
3. **三本账簿**：金、蓝、绿三本，作为章节标志。
4. **抽屉**：开头埋伏笔，假片尾回收。
5. **两毛钱**：首尾菜市场呼应。
