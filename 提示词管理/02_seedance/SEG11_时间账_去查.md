# SEG11 时间账·左半屏"去查"

| 项目 | 内容 |
|---|---|
| 剧本镜头 | S22 左半 |
| 模式 | 全能参考，横屏 16:9，720P |
| 可用时长 | 0–12s |
| 上传顺序 | @图片1 = K11 首帧，@图片2 = C01 老周（外出），@图片3 = L07 体检中心大厅 |
| 用法 | Claude 在 R10 里把画面**中间竖条**裁出来放在分屏左边，配上"8:00 → 11:30"的时钟数字 |
| 对白 | 无（算盘爷的画外音后期配：见 `04_音频`） |

## 提示词

```
以@图片1作为第一帧。老周穿外出服装，外形严格参考@图片2；场景参考@图片3的体检中心大厅。

整段是延时摄影的感觉，镜头固定不动，人物始终在画面正中央：墙上的大挂钟指针飞快地转，从8点转到11点半。前景里的老周依次快速完成几件事，每件事一两秒：伸出胳膊在抽血窗口抽血、按着棉签走开、坐下来量血压、走进一扇检查室的门又走出来。周围穿浅蓝色衣服的护士和其他体检的人像快进一样快速流动，变成模糊的拖影。
最后3秒（12–15秒）：节奏恢复正常速度。老周走出大厅，站在门口的阳光下，舒舒服服地伸了个大懒腰，一脸轻松，看看手表，笑了。

音效：轻快的脚步声、"嘀"的叫号声，快进时声音也加速。

【风格】2D卡通动画风格，与参考图完全一致：统一粗细的深褐色描边，平涂上色加一层简单阴影，简单夸张的造型，大头小身体，明亮温暖的室内光，暖色调。画面流畅，表情清晰，节奏轻快。
【约束】保持2D平面卡通画风，不要变成3D或立体光影，线条在运动中保持稳定、不抖动、不闪烁；老周外形必须与参考图完全一致，全程不变脸；人物始终在画面中央竖条区域内（之后要裁成竖条）；钟面上没有数字，画面中不出现任何可读文字、字幕、水印；不要背景音乐，没有对白，保留音效。
```
