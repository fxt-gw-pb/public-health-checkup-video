## 提示词

```
以@图片1作为第一帧。老周穿@图片2中间那一套伪装造型（黑色大墨镜、白色口罩、黑色鸭舌帽、夹克领子竖起），外形严格参考@图片2；老刘严格参考@图片3，但他也戴着黑色大墨镜和白色口罩；场景参考@图片4的体检中心门口，清晨暖金色晨光。老周的声音与@音频1一致；如果提供了@音频2，老刘的声音与@音频2一致。

镜头1（0–5秒）：中景。老周后背贴着墙根，踮着脚，横着身子一点点往大门方向挪，左看看、右看看，像特务一样鬼鬼祟祟。
镜头2（5–8秒）：中景。老周刚走到墙角拐角处，拐角后面迎面走出来一个同样戴着墨镜和口罩的瘦高个，两个人差点撞个满怀，同时往后跳了一步，僵在原地，互相盯着。
镜头3（8–11秒）：双人近景。两个人同时、慢慢地摘下墨镜、拉下口罩——是老刘。两人四目相对，空气凝固。
镜头4（11–15秒）：双人中景。老周伸手指着老刘（中年男声，又惊又气）："你不是说体检是收割吗？！"老刘手里攥着一个透明的小塑料尿杯，赶紧往身后藏，挺起胸强装镇定（瘦高男声）："我……我来看看它怎么收割的。"最后1秒两人保持对峙的姿势。

音效：鬼祟的踮脚声、差点相撞的"哎！"、摘墨镜的轻响。

【风格】2D卡通动画风格，与参考图完全一致：统一粗细的深褐色描边，平涂上色加一层简单阴影，简单夸张的造型，大头小身体，暖金色晨光，暖色调，中国北方城市生活气息。画面流畅，动作有卡通弹性（挤压与拉伸），表情夸张清晰，喜剧节奏。
【约束】老周和老刘是两个完全不同的人：老刘又高又瘦、长脸、两撇八字胡，比老周高半个头；老周圆脸、啤酒肚、左眉尾有痣；画面里只有这两个人；保持2D平面卡通画风，不要变成3D或立体光影，线条在运动中保持稳定、不抖动、不闪烁；所有角色和场景必须与参考图完全一致，全程不变脸；摘下墨镜口罩后的脸必须与参考图一致；画面中不出现任何可读文字、字幕、水印；不要背景音乐，保留对白和音效。
```

## 生成后检查
- [ ] 摘下墨镜后能一眼认出老刘（八字胡、长脸）
- [ ] 尿杯是透明小塑料杯，不要做得太显眼或不雅
- [ ] 老刘的声音满意的话，截取作为 A-老刘
