# SEG12 时间账·右半屏"不查"

| 项目 | 内容 |
|---|---|
| 剧本镜头 | S22 右半 |
| 模式 | 全能参考，横屏 16:9，720P |
| 可用时长 | 0–14s |
| 上传顺序 | @图片1 = K12 首帧（日历），@图片2 = C01 老周（外出），@图片3 = C05 配角组，@图片4 = L08 医院走廊，@图片5 = L03b 客厅日 |
| 用法 | Claude 在 R10 里裁出画面中间竖条放在分屏右边，配上日历年份翻动的数字 |
| 对白 | 无（画外音后期配） |
| 分寸 | 讲的是"耽误时间、错过生活"，**不渲染病痛**，保持诙谐 |

## 提示词

```
以@图片1作为第一帧。老周外形严格参考@图片2；小孙子参考@图片3中4岁和8岁的男孩；医院走廊参考@图片4；客厅参考@图片5。所有画面的主体都在画面正中央。

镜头1（0–4秒）：特写，固定机位。墙上的手撕日历一页接一页飞快地自己撕落，纸页像蝴蝶一样从画面中飞走（纸页上没有可读文字和数字）。
镜头2（4–8秒）：@图片4的医院走廊，色调略偏冷但仍然是可爱的卡通风格。老周手里捏着一沓单子，排在一条长长的队伍里，队伍几乎不动。他踮脚往前看看，又低头看看手表，长长地叹了一口气，肩膀垮了下来。
镜头3（8–11秒）：@图片5客厅右后方的墙角特写。那根靠在墙角的鱼竿上落满了灰，鱼竿和墙角之间结了一张卡通的蜘蛛网，一只小蜘蛛慢悠悠地爬过。
镜头4（11–15秒）：中景。4岁的小孙子戴着黄色幼儿园小帽，冲着画面外挥手喊"爷爷"；他原地转了一个圈，转完之后已经长成背着蓝色双肩书包的8岁小学生，还在挥手，但表情有点失望。最后1秒保持不动。

音效：日历撕纸声、走廊里叫号的回声、叹气声、孩子的"爷爷——"。

【风格】2D卡通动画风格，与参考图完全一致：统一粗细的深褐色描边，平涂上色加一层简单阴影，简单夸张的造型，大头小身体，色调略偏冷但整体温和、不阴森，带一点诙谐。画面流畅，表情清晰。
【约束】保持2D平面卡通画风，不要变成3D或立体光影，线条在运动中保持稳定、不抖动、不闪烁；所有角色必须与参考图完全一致，全程不变脸；主体始终在画面中央竖条区域内；不出现血、病床、输液等令人不适的医疗画面；画面中不出现任何可读文字、数字、字幕、水印；不要背景音乐，保留音效。
```
