# 配音、音乐与音效

## 1. 声音一致性方案

Seedance 2.0 会为对白生成声音和口型，但**每一段的声音可能都不一样**。按下面三步保持一致：

1. **先抽出"标准声音"**：SEG02（老周）、SEG04（算盘爷）、SEG08（李医生）、SEG13（老刘）这几段生成满意后，由 Claude 从视频里截出 5–10 秒干净的单人对白，存进 `素材/07_音频参考/`：
   `A-老周.wav`、`A-算盘爷.wav`、`A-李医生.wav`、`A-老刘.wav`
2. **后续段落上传参考音频**：在"全能参考"模式里作为 @音频1/2/3 上传（每段最多 3 段，合计不超过 15 秒），提示词里已经写好"声音与@音频1一致"。
3. **兜底：后期统一重配**。如果声音还是对不上，就用同一个 TTS 音色（或组员真人）把全片台词重新配一遍，Claude 按原视频口型对齐时间轴替换。

## 4. 背景音乐（后期统一加，Seedance 里都不生成音乐）

| 段落 | 情绪 | 音乐建议 |
|---|---|---|
| SEG01–SEG02 | 市井、俏皮 | 轻快的拨弦 + 木琴，带一点民乐（如三弦、梆子点缀） |
| SEG03–SEG04 | 神秘、滑稽 | 音乐渐弱，只剩低音提琴拨弦，算盘醒来时用一个"叮"的钟琴 |
| SEG05–SEG09 金钱账 | 轻快、推进 | 回到主旋律，节奏加快；SEG07 加速到"停停停"时急停 |
| SEG10–SEG14 时间账 | 分屏对比 → 喜剧 | 分屏时左轻快、右放慢；墨镜相遇用两下定音鼓"咚、咚"；早点摊温暖 |
| SEG15 恐慌 | 夸张紧张 | 低音铜管"嘟——"一声 + 警报，算珠弹脑门时音乐急停 |
| SEG15–SEG16 | 温和、可靠 | 钢琴 + 拨弦，暖 |
| SEG17 假片尾 | 煽情 → 打断 | 温暖钢琴渐强 → 唱片划停"刺啦" → 静默半秒 |
| SEG18 + 片尾卡 | 轻松收尾 | 主旋律完整再现，在三声"咔哒"上收住 |
